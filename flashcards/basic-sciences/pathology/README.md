# Patoloji

TUS için yüksek verimli, seçenek eleme odaklı patoloji kartları. Amaç tüm patolojiyi kataloglamak değil; ayırt ettirici mekanizmaları, morfolojik bulguları, genetik eşleşmeleri ve klinik örüntüleri tanımaktır.

Kart sayısı kota değildir; her konu için en küçük etkili set tercih edilir. İlgili TUS soru başına 20 kart kesin üst sınırdır, hedef değildir.
