# Farmakoloji

TUS için yüksek verimli, mekanizma ve ayırt edici yan etki odaklı farmakoloji kartları. İlaç katalogu oluşturmak yerine sınıf mekanizmaları, karakteristik toksisiteler, antidotlar ve klinik seçenek ayırıcıları önceliklendirilmiştir.

Kart sayısı kota değildir; her konu için en küçük etkili set tercih edilir. İlgili TUS soru başına 20 kart kesin üst sınırdır, hedef değildir.
