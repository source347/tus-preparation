## Anatomi

[Anatomi desteleri](anatomy/README.md) depoda korunmaktadır (14 deste, 463 kart); önceki kapsam kararı doğrultusunda bu yüksek verimli çalışma setine dahil edilmemiş ve genişletilmemiştir.

## Kart ilkeleri

- Klinik ipuçları, mekanizmalar, hız kısıtlayıcı basamaklar ve klasik ayırıcı özellikler önceliklidir.
- Kartlar, doğru seçeneği benzer çeldiricilerden ayırmaya yardım etmelidir.
- Tekrar, düşük verimli ayrıntı ve gereksiz kataloglama azaltılır.
- Her deste için kaynakça ilgili konu README dosyasında belirtilir.
