# Fizyoloji

TUS için yüksek verimli, seçenek eleme odaklı fizyoloji kartları. Kart sayısı kota değildir; her deste yalnızca ayırt ettirici temel mekanizmaları ve sık sınanan klinik-fizyolojik ilişkileri içerir. İlgili TUS soru başına 20 kart kesin üst sınırdır.
