# Mikrobiyoloji

TUS için yüksek verimli, seçenek eleme odaklı mikrobiyoloji kartları. Kart sayısı kota değildir; her deste ayırt ettirici organizma özellikleri, virülans mekanizmaları, tanı ipuçları ve klinik eşleştirmelerle sınırlandırılmıştır. İlgili TUS soru başına 20 kart kesin üst sınırdır.
